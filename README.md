## 🚀 How to Run Locally

### Option 1: Direct Browser Open
Simply double-click `index.html` or right-click and choose **Open With > Google Chrome / Microsoft Edge / Firefox**.

### Option 2: Using Python's Built-in Server
Open PowerShell or Command Prompt in the `portfolio` folder:
```powershell
cd d:\agentOS\portfolio
python -m http.server 3000
```
Then visit: `http://localhost:3000`

## 🌐 Free 1-Click Deployment Options

### 1. GitHub Pages (Recommended)
1. Push this `portfolio` directory to a GitHub repository (e.g., `username/portfolio` or `username.github.io`).
2. Go to **Settings > Pages** in your repository.
3. Under **Branch**, select `main` and root `/` folder, then click **Save**.
4. Your site will be live at `https://<username>.github.io/<repo-name>/`.

### 2. Vercel
1. Install Vercel CLI: `npm i -g vercel` or log in to [vercel.com](https://vercel.com).
2. Run `vercel` inside the `portfolio` folder, or import your GitHub repository.

### 3. Netlify Drop
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the `portfolio` folder.
3. Your site is live instantly with an SSL certificate.
